# Crime Analytics in Washington, D.C.
Team members: Myles Lewis, Kiet Ly
Overview: This dataset contains a subset of crime locations within Washington DC which are reported in the Analytical Services Application database by the District of Columbia Metropolitan Police Department.
Source: https://opendata.dc.gov/datasets/74d924ddc3374e3b977e6f002478cb9b_7/explore?location=38.888659%2C-76.991409%2C17.
